更新日期：2026-08-20

## 模型用途

该模型为外壳设计提供统一的 PCB 基准、接口实体、安装孔、Z 向包络和散热接触关系。它不是主板厂商 CAD，也不用于生产或维修主板本身。

物理实体与避让体分开导出：

```text
主板物理参考
├── PCB + 四个安装孔
├── 04/06 接口实体 + 板载开关
└── 散热组件
    ├── 冷板 / 支撑
    ├── 风扇托板
    ├── 鼓风机壳与转子示意
    ├── 热桥
    └── 鳍片

独立避让参考
├── 散热组件包络
├── 底面器件包络
└── 四孔装配轴线
```

## 已作为机械基准的数据

| 项目 | 当前值 |
| --- | ---: |
| PCB | 100.0 × 105.5 × 1.5 mm |
| PCB 底面 / 顶面 | Z=0 / Z=1.5 mm |
| PCB 底面至最低器件 | 10.25 mm |
| PCB 顶面至风扇最高面 | 13.8 mm |
| 裸组件实测总厚度 | 约 25.6 mm |
| 安装孔直径 | Ø3.2 mm |
| 风扇中心 | X=-0.20, Y=-3.45 mm |
| 风扇进气口 | Ø33.5 mm |
| 04 双 USB 相对 PCB 04 边突出 | 约 2.0 mm（用户粗测，当前最大值） |
| 06 两个 USB 相对 PCB 06 边突出 | 约 1.0 mm（用户粗测） |
| 04 鳍片相对 PCB 04 边突出 | 0.0 mm（与 PCB 边齐平） |

四个孔没有按对称关系重猜，而是逐孔保存：

| 角位 | X / mm | Y / mm |
| --- | ---: | ---: |
| 07/06 | +45.387 | +48.561 |
| 07/04 | -44.982 | +48.430 |
| 05/06 | +44.895 | -49.020 |
| 05/04 | -45.107 | -48.959 |

照片标定带来的孔位不确定度记为 ±0.35 mm。04/06 接口中心直接读取 [n305_panel_reference.py](../src/n305_panel_reference.py)，与已审阅的正投影图共用同一数据源。

01/02 卡尺照片确认的是 PCB 平面 `100.0 × 105.5 mm`，卡爪没有测量接口鼻端，因此不存在可据此建立的 `103.4 mm` 对称接口包络。接口前沿必须逐件保存：04 叠层双 USB 当前到 `X=-52.0 mm`，06 两个 USB 到 `X=+51.0 mm`，04 鳍片外沿与 `X=-50.0 mm` PCB 边齐平。04 的 DC、HDMI、耳机和 RJ45 只知道“略凸”，当前使用 `1.0 mm` 的显式 provisional 外观代理，受 04 面约 `2.0 mm` 最大粗测值约束，不能当作逐件实测。

板载开关不能从 `X=50` 的外接矩形边推导。03俯视图显示开关触点比06 USB 前沿约内退 `1.2 mm`，其相邻 PCB 外形还有局部台阶；06侧视图同时显示 USB 是更高的墙面约束件。当前照片代理把 USB 前沿放在 `X=51.0 mm`、开关触点放在 `X≈49.8 mm`，平面不确定度暂记 `±0.4 mm`。开关不参与接口总包络，也不应作为面板孔对板载实体的穿墙覆盖目标；Ø9.4 孔应覆盖用户实测 Ø9.2 的原按钮穿孔段。

PCB STEP/STL 目前仍使用完整 `100 × 105.5 mm` 外包络作为保守碰撞体，不从单张照片虚构局部台阶的精确切口。局部内缩已用于开关/墙面关系，但尚未作为已测 PCB 轮廓切入实体；这会高估而不会低估墙体碰撞风险。

风扇外壳使用 [01 照片 PCB 对齐轮廓](../previews/calibration/01-blower-profile-trace.png)，当前包围范围约为 `X=-29.2…+25.4 mm、Y=-34.0…+19.8 mm`，保留朝 04 的出风蜗舌以及偏置进风口。叶轮改为 32 片后弯叶片，不再使用三根径向杆示意。机器转换记录见 [component-calibration.json](./component-calibration.json)。

01 顶视照片中可见的双孔长条不能用于确定 Z 高度；05 侧视照片也不支持它位于风扇上表面。旧模型中悬在风扇顶部的长条已删除，不再计入实体或避让包络。若以后需要还原该零件，必须先从侧视证据确定它与 PCB 的安装关系，不能再根据顶视遮挡关系猜高度。

## 散热组件不再悬空

模型显式建立以下连续路径：

```text
PCB → 冷板/支撑 → 风扇托板 → 热桥 → 鳍片
                       └──────→ 鼓风机壳
```

[接触链侧视图](../previews/reference/cooling-contact-path.png)用于视觉复核；构建脚本还会检查相邻件零距离且存在有效接触/交叠体积。数值结果见 [validation.json](../exports/reference/validation.json)。

这里的“接触”是壳体设计所需的拓扑和包络约束，不表示已经还原真实导热材料、螺钉、弹簧压力或内部热管截面。

## 精度分层

已测量或 PCB 对齐：PCB 总体外接包络和厚度、总 Z 包络、四孔、接口中心、板载开关 Y/Z 中心、风扇中心/进气口以及已确认的面板开孔尺寸。

照片重建或保守近似：PCB R4 圆角、06开关相对 USB 的 `1.2 mm` 平面内退和相邻 PCB 台阶、04 非双 USB 接口的 `1.0 mm` 前伸代理、连接器隐藏壳体的深度/局部外形、冷板支撑和热桥细节、风扇蜗壳折线间的曲率、叶片厚度/曲率、鳍片厚度/节距、底面器件块状避让体。双孔长条因缺少可靠的 Z 向证据而不建模。上述近似在源码和验证 JSON 中不得表述成用户实测值。

尤其要区分：面板孔的尺寸不等于板载接口实体的鼻端尺寸；未来外壳 CAD 应直接读取面板参数，并用接口实体/插头通道做覆盖校验。

## 本轮审阅重点

1. 四孔和 PCB 朝向是否正确。
2. 04 的 DC、HDMI 1、耳机、RJ45、双层 USB、HDMI 3 是否按 `+Y→-Y` 排列。
3. 06 两个 USB 是否水平并共享同一 Z 中心；开关是否位于偏 07 一侧。
4. 散热器是否在 04 一侧，风扇中心和鳍片跨度是否符合照片。
5. 底面保守避让体是否需要进一步拆分或缩小。

确认这些内容后，才进入外壳开孔覆盖与装配面的三维阶段。
