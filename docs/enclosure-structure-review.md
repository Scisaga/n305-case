# N305 外壳结构定义审阅

更新日期：2026-08-21

状态：**结构检查已通过，并已按本参数源生成 V2 试装版 STEP/STL；尚不是最终量产版。**

本文件记录“外壳由哪些面组成、怎样装配、怎样夹紧、接缝在哪里、开孔能否覆盖功能区域”。同一参数源现已用于用户授权的 V2 试装版；预览图本身仍不是制造文件，实际 CAD 与全部试制参数见 [V2 伴随说明](../exports/enclosure/v2-prototype/README.md)。

## 2. 包络和壁厚

| 参数 | 当前值 | 状态与依据 |
| --- | ---: | --- |
| 内腔宽 X / Y | 约 103.0 / 105.9 mm | X 为用户对原壳的实测；Y 为 PCB 105.5 + 05/07 各 0.20 mm 试装余量 |
| X 向外宽 | 106.6 mm | derived：内腔 103.0 + 两侧 1.8 mm 壁 |
| Y 向外宽 | 109.5 mm | derived：内腔 105.9 + 两侧 1.8 mm 壁 |
| 裸组件 Z 包络 | -10.3…+15.3 mm | 当前主板验证包络，合计 25.6 mm |
| 顶板 / 底板 | 1.2 / 1.2 mm | 用户确认，精确值 |
| 内侧加强筋 | 宽 1.5 / 高 0.8 mm | 已审阅并进入 V2；有筋处局部总厚度 2.0 mm |
| 壳体 Z 向外厚 | 28.0 mm | 25.6 + 1.2 + 1.2；没有风扇额外间隙 |
| 侧壁 | 1.8 mm | 用户对原壳的实测；不改变面板孔标称尺寸 |
| XY 外轮廓圆角 | R5.8 mm | derived provisional：内 R4 + 1.8 mm 壁厚，构成等壁厚偏置 |
| XY 内腔圆角 | R4 mm | provisional：照片重建的 PCB 圆角，尚无物理实测值 |

顶板和底板的 `1.2 mm` 是连续基础板厚，不因加强筋而改写。已批准的稀疏筋从内表面增加 `0.8 mm`：顶筋在 XY 平面绕开完整风扇蜗壳和鳍片投影，底筋绕开最低的 04 堆叠双 USB，并同时对当前完整主板实体检查。实体交叠均为 `0.000 mm³`；筋已经与各自壳体融合为单一有效实体，不增加外包络。路径、距离和三维审图见[加强筋审阅](./enclosure-reinforcement-review.md)。

04 和 06 都是连续实体侧壁，只从整面墙中切除已经审阅的贯通孔和 04 鳍片出风包络。它们不承担 PCB 贴边定位。原壳 04–06 内距约 `103.0 mm`，当前结合两侧最大 USB 突出量暂分配为：04 内壁 `X=-52.0 mm`（距 PCB `2.0 mm`），06 内壁 `X=+51.0 mm`（距 PCB `1.0 mm`）。这使两侧 USB 前沿分别成为对应墙面的局部轴向基准，而不是让板载开关伸进墙体。

原壳 05–07 内距约 `110.5 mm` 包含额外留空，用户明确认为不需要参考，因此不进入当前外壳尺寸。05/07 恢复为各 `0.20 mm` 紧凑试装余量，当前 Y 向内距为 `105.9 mm`。PCB 的主要 XY 定位与两壳夹紧仍由原有四孔/螺柱完成。这些侧向尺寸不是上下壳接缝，也不是额外打印补偿。

接口突出量不再共享一个对称平面：04 叠层双 USB 粗测约 `2.0 mm`，06 两个 USB 粗测约 `1.0 mm`，04 鳍片外沿与 PCB 齐平；04 其余接口暂用 `1.0 mm` provisional 代理。按当前分配，两侧最大 USB 前沿都与内墙面名义相齐，在 `1.8 mm` 厚墙孔内形成与原壳一致方向的退入式接口通道，而不是让接口主体穿透整面墙。

03 俯视和 06 侧视共同确认 06 墙面轴向关系应由两个 USB 约束；开关触点比 USB 前沿约内退 `1.2 mm`，当前代理位于 `X≈49.8 mm`，距 06 内墙 `X=51.0 mm` 约 `1.2 mm`，不会进入墙孔。开关附近 PCB 的局部内缩轮廓不能再被 `100 mm` 外接矩形替代。`Ø9.4 mm` 按钮孔覆盖的是 `Ø9.2 mm` 原按钮穿孔段，不是板载触点本体。侧壁厚也已复原为原壳实测 `1.8 mm`，因此按钮的穿墙长度条件比旧版 `1.2 mm` 假设更接近原件；按钮静止位置与有效行程仍需实物试按确认。

当前主板实体仍保留 `100 × 105.5 mm` 完整外包络作为保守碰撞体，没有凭照片猜切局部 PCB 台阶的精确轮廓；但开关实体和墙面基准已脱离这条虚构直边。因为完整外包络比真实内缩 PCB 更占空间，只要它与墙体无碰撞，补回真实台阶不会恶化外壳净空。后续若需要外观级主板复刻，再单独对 03 照片做局部正投影描边。

四孔进一步锁定了这个推导。04 侧两根安装轴到 `X=-52.0 mm` 内墙分别约为 `7.018/6.893 mm`；06 侧两根安装轴到 `X=+51.0 mm` 内墙分别约为 `5.613/6.105 mm`。上下壳的柱位读取这些原孔坐标后，主板不能再沿 X 平移，因而不会把开关意外推入按钮孔。同时，`100.0 + 2.0 + 1.0 = 103.0 mm`，PCB 与两侧最大 USB 前沿的总跨度恰好闭合原壳内距。

按钮轴向链的当前估算为：外墙到内墙 `1.8 mm`，内墙到触点名义 `1.2 mm`，所以外表面到开关触点名义约 `3.0 mm`。只计 03 照片给出的 `±0.4 mm` 平面不确定度，内墙到触点约为 `0.8–1.6 mm`，外表面到触点约为 `2.6–3.4 mm`；这里尚未计入 USB“约 1 mm”粗测误差。原按钮本来就是为 `1.8 mm` 原壳墙厚和该主板安装关系工作的，因此复用的几何可信度较高；唯一不能由现有照片直接证明的仍是被遮挡推杆的自由长度与实际触发行程。

主板参考中的隐藏连接器主体只是保守方盒，并非实测轮廓。把 04/06 面退到 PCB 边后，这些代理方盒会与面板发生名义交叠；本轮只记录该交叠，不用它擅自放大原壳孔。实体检查改为：PCB 本体与六面零体积穿插、非接口面与完整主板模型无交叠、外部孔仍按权威尺寸完成覆盖。真实连接器后部若影响最终壁厚，需要补充实测截面后再处理。

圆角是真实参数化实体，不是渲染修饰。先前的“外 R10 + 内 R4 + 小幅外扩”并不满足包含关系，而旧验证只检查体积相交，错误地给出通过。本版已经删除该组合。现在外轮廓是扩大后的内腔轮廓向外等距 `1.8 mm` 的结果，因此外圆角为 `R4 + 1.8 = R5.8`，直边和圆角的名义壁厚一致。R4 仍是待实测的 provisional 内腔圆角，不表示圆弧与 PCB 零间隙接触。

新增验证同时检查：完整 PCB 平面是否被扩大后的内腔包含、04–06 内跨距是否为 `103.0 mm`、05/07 是否各为 `0.20 mm`、侧壁是否为 `1.8 mm`、06 内墙是否采用 USB 前沿而非开关触点作为基准、非对称 X 边界是否正确平移整个圆角实体、外轮廓与内腔理论等距偏置是否双向一致，以及开孔后 04/06 是否仍各为一个连续墙体实体。这些项目不能再由“PCB 与壳体相交体积为零”替代。PCB R4 本身仍是照片近似，待实物测量后会联动更新内外两个圆角。

当前验证要求为：PCB 完全位于内腔中；04/06 分配为 `2.0/1.0 mm`，05/07 为 `0.20/0.20 mm`；理论等距偏置相对当前外轮廓的缺失和多余体积均为 `0.0 mm³`；直边壁厚和圆角径向壁厚均为 `1.8 mm`；04/06 开孔后分别保持单一连续实体。最终数值以本轮重新生成的 [内部验证](./enclosure-structure-validation.json) 为准。

## 3. 一条闭合六段接缝

上下壳的边界是一条闭合路径：

```text
顶面—04 → 顶面—07 → 06—07 竖角 → 底面—06
     → 底面—05 → 04—05 竖角 → 回到顶面—04
```

- 两个右侧圆角（06/07、06/05）完整归 06/上壳；两个左侧圆角（04/07、04/05）完整归 04/下壳，任何圆角曲面上都没有分件缝。
- 06/07 竖缝退到 `X=+47.0 mm` 的 +Y 直边切点；04/05 竖缝退到 `X=-48.0 mm` 的 -Y 直边切点。两值不再强制关于原点对称，因为 04/06 单侧分配是 `2.0/1.0 mm`。
- 顶面/04、顶面/07、底面/06、底面/05 使用齐平对接；圆角转弯属于对应的完整单壳实体。
- 上壳内部的顶面—06—05，以及下壳内部的底面—04—07，均为同一零件的连续连接，不是装配缝。
- 当前名义 CAD 缝隙为 `0.0 mm`，没有嵌入制造补偿。若以后打印工艺确实需要补偿，必须另设参数并再次审阅，不能污染零间隙结构基准。
- 不使用连续卡槽、连续内搭边、整圈舌槽或独立框架。

详见 [六面归属和接缝图](../previews/enclosure/face-ownership-and-seam.png)。

爆炸图中圆角会完整地跟随其所属壳体移动，不再出现“半个圆角”。中段实体布尔检查确认：四个圆角的总缺料体积均为 `0.0 mm³`，且每个圆角由单一壳体独立覆盖，曲面上不存在上下壳分割。详见 [圆角接缝局部图](../previews/enclosure/rounded-corner-seam-detail.png)。

## 4. 四孔夹紧和安装顺序

四根轴完全读取主板现有四孔，不增加壳体安装孔：

| 孔 | X / mm | Y / mm |
| --- | ---: | ---: |
| 07/06 | +45.387 | +48.561 |
| 07/04 | -44.982 | +48.430 |
| 05/06 | +44.895 | -49.020 |
| 05/04 | -45.107 | -48.959 |

典型夹紧链为：

```text
底部紧固件 → 下壳套柱 → PCB 底面 → PCB → 上壳柱 → 上壳顶面
```

安装顺序：

1. 上壳外顶面朝下放置，内部向上。
2. 主板沿 `+Z` 放到四个上壳柱的平端面；没有打印结构伸入 PCB 孔。
3. 先让下壳中两颗对角螺钉略微伸出套柱，螺钉杆进入原 PCB 孔完成临时对中，再沿 `+Z` 合上下壳。
4. 四颗螺钉全部松起牙、六段接缝闭合后，再从底面均匀锁紧。

审阅几何暂用 `Ø6.4 mm` 平端柱、`Ø3.4 mm` 下壳通孔以及 `Ø2.5 mm` 上壳导孔。旧图中的 `Ø3.0 mm` 定位鼻已删除：它围绕 `Ø2.5 mm` 导孔时径向壁厚只有 `0.25 mm`，不适合打印，也没有必要。M3 仅由 `Ø3.2 mm` PCB 孔推断，螺钉头、热熔螺母或自攻形式尚未决定。四根柱与当前接口、散热组件和底面避让体均无碰撞。详见 [四孔夹紧剖面](../previews/enclosure/four-hole-clamp-section.png)。

## 6. 本轮需要审阅的项目

1. 是否确认“上壳=顶+06+05，下壳=底+04+07”的对角三面壳。
2. 是否接受一条六段闭合缝；两条跨壳竖缝位于直边切点，圆角曲面不再分割。
3. 原壳 04–06 内跨距 `103.0 mm` 与侧壁 `1.8 mm` 已进入参数源；04/06 暂按接口突出量分配 `2.0/1.0 mm`，05/07 保持各 `0.20 mm`。原壳 05–07 的 `110.5 mm` 不作为本版尺寸依据。PCB 由原四孔/螺柱主要定位；仍需物理确认 provisional R4。
4. 是否接受四孔夹紧链的方向；紧固件头型和螺纹形式仍需选择。
5. 04 鳍片区域是保留 `84 × 7.4 mm` 连续功能包络，还是下一步按原壳外观设计格栅，但必须证明不阻挡出风。
6. 是否接受两个 HDMI 在本阶段保持“六边形孔已确认、真实连接器前端未建模、覆盖不计算”。
