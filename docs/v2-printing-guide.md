# N305 V2 外壳打印、下单与试装指南

更新日期：2026-08-21

适用版本：`v2-prototype-2026-08-21-ribbed`

状态：试装指南，不代表当前 CAD 已达到量产状态。

## 1. 先给结论

本项目当前最稳妥的制造路线是：

1. 先用 **FDM + PETG** 低成本打印一套完整上下壳，验证主板能否放入、四孔是否同轴、接口是否能插拔、原按钮是否会误压开关。
2. 把实测结果写回 CAD，不要只在切片软件里整体缩放或临时磨掉干涉处。
3. 尺寸收敛后，再用国内工业打印平台下单 **MJF/SLS + PA12 或 PA12S 尼龙**，作为长期使用的功能样机。

如果不方便使用 FDM，也可以直接下单 PA12，但必须把本页第 5 节列出的薄壁、间隙和未确认项交给平台工程师审核。当前版本是试装版，一次下单成功不等于所有 provisional 参数已经得到验证。

## 2. 应该提交哪些文件

打印时只提交两个独立零件：

- [上壳 STL](../exports/enclosure/v2-prototype/n305_v2_upper_shell.stl)
- [下壳 STL](../exports/enclosure/v2-prototype/n305_v2_lower_shell.stl)

STEP 文件用于修改、工程审核或平台要求实体模型时提供：

- `n305_v2_enclosure_assembly.stl`

装配文件包含上下壳闭合位置，只用于总体检查。嘉立创的当前下单规则也要求一个文件不要包含多个模型或成套装配体，并明确支持 STL、STP、STEP、OBJ 和 3MF；其官方建议生产上传 STL。[嘉立创下单须知](https://www.jlc-3dp.cn/technicalColumnsDetails/40026.html)

上传后必须检查：

| 项目 | 正确结果 |
| --- | --- |
| 单位 | mm |
| 数量 | 上壳 1 件、下壳 1 件 |
| 每个零件的预览外包络 | 约 `106.6 × 109.5 × 26.8 mm` |
| 闭合后的总厚度 | `28.0 mm`，不是单件上传尺寸 |
| 自动缩放 | `100%` / `1.000` |
| 模型方向 | 方向变化不应改变尺寸；不得镜像 |

STL 本身是三角网格，通常不可靠地携带单位信息；看到平台预览尺寸不符时应停止下单，不能用“看起来差不多”判断。STEP 保留精确实体和单位，更适合作为 DFM 审核附件，但不要把同一个零件的 STEP 和 STL 当成两件商品重复下单。

完整参数、文件哈希和自动验证结果分别见 [manifest.json](../exports/enclosure/v2-prototype/manifest.json) 与 [validation.json](../exports/enclosure/v2-prototype/validation.json)。

> 本次重新生成前已经上传到平台的同名 STL 不会自动更新。新模型已融合 `1.5 × 0.8 mm` 内侧加强筋；已有订单或购物车必须删除旧文件并重新上传。新文件预览体积应约为：上壳 `24.13 cm³`、下壳 `23.02 cm³`；旧截图中的约 `23.66/22.31 cm³` 说明仍是无筋旧文件。

## 3. 材料和工艺怎么选

### 推荐的两阶段方案

| 用途 | 工艺和材料 | 结论 |
| --- | --- | --- |
| 第一次尺寸试装 | FDM PETG | 首选低成本方案；韧性和耐热性比 PLA 更适合通电前后的机壳试验，但孔和接口边缘精度依赖打印机标定 |
| 尺寸收敛后的功能样机 | MJF PA12S / PA12 | 首选外包方案；无需支撑、韧性较好，适合复杂外壳、螺柱和反复拆装 |
| 仅看外观或短时无电试装 | FDM PLA | 可以，但不建议作为通电长期使用外壳 |
| 有封闭腔体且已熟练调机 | FDM ABS / ASA | 可用，但当前约 107 × 110 mm 的大薄板更容易翘曲，不作为首次试打默认选项 |
| 整套外壳 SLA 普通/类 ABS 树脂 | 不推荐当前版本 | 大平板、细螺柱和螺钉夹紧对收缩、脆裂及耐热更敏感；当前 `1.2 mm` 板厚也低于嘉立创类 ABS40 的 `1.5 mm` 推荐壁厚 |
| 碳纤增强材料 | 暂不推荐 | 成本、喷嘴和表面磨蚀要求更高，试装阶段没有必要；含碳材料还不适合作为未评估的电子绝缘假设 |

嘉立创将树脂定位为高精细外观材料，将尼龙定位为功能件材料，并提示树脂存在收缩、受热变形风险。[嘉立创下单须知](https://www.jlc-3dp.cn/technicalColumnsDetails/40026.html) 其 PA12/PA12S 资料说明两者可采用 MJF/SLS 无支撑成型；PA12S 还给出约 `±0.25～0.3 mm` 的尺寸公差及 `1.0 mm` 最小壁厚能力。[PA12S 官方资料](https://www.jlc-3dp.cn/technicalColumnsDetails/60903.html) [PA12 官方资料](https://www.jlc-3dp.cn/technicalColumnsDetails/61261.html)

这些数值是服务商的工艺/材料声明，不是本项目的实物验收结果。尤其不能用材料页的“最小壁厚”代替本项目的大平板翘曲审核。

### 为什么不直接把 PLA 当成最终材料

PLA 适合快速、便宜地确认外形，但带风扇的小主机内部存在持续热源。材料供应商的公开数据也显示，常见 PETG 的热变形温度高于其基础 PLA 对照材料；实际结果仍随配方和打印条件变化。[Bambu PETG HF 官方数据](https://eu.store.bambulab.com/en-mt/products/petg-hf)

因此：PLA 只用于无电或短时尺寸确认；PETG 用于第一套完整试装；长期功能样机优先 PA12。任何材料若没有明确的阻燃等级，都不能因为“是工程塑料”就默认具有阻燃认证。

## 5. 当前 V2 下单前必须知道的风险

自动验证已经确认 STEP/STL 可回读、上下壳均为单个有效实体、没有几何体积重叠，且已计算的开孔覆盖没有失败。但打印工艺会引入模型验证无法覆盖的误差：

| 风险 | 当前参数 | 为什么要关注 |
| --- | ---: | --- |
| 大面积薄板 | 顶、底基础各 `1.2 mm`；筋宽 `1.5 mm`、高 `0.8 mm` | 筋路处局部总厚度为 `2.0 mm`，变形风险低于无筋旧版，但筋间板面仍处在服务商壁厚边界，不能据此忽略翘曲审核 |
| 05/07 紧凑余量 | 每侧 `0.20 mm` | 小于或接近多数打印工艺的单件尺寸波动，实际可能紧配甚至干涉 |
| 上下壳接缝 | CAD 名义间隙 `0.0 mm` | 实物不会自动获得完美零缝；毛边、翘曲和孔位误差都会阻止闭合 |
| 04/06 内跨距 | `103.0 mm` | 由原壳内距和 USB 突出量建立，接口前沿接近墙体基准，不能靠强压装入 |
| 上柱导孔 | `Ø2.5 mm` | 目前只定义为 M3 级 provisional 方案，尚未确定攻丝、塑料自攻或嵌件 |
| 下柱通孔 | `Ø3.4 mm` | 没有螺钉头沉孔或沉头，螺钉头会露在底面 |
| 原按钮 | 穿墙部分 `Ø9.2 mm`，壳孔 `Ø9.4 mm` | 理论直径余量只有 `0.2 mm`；打印收缩、孔毛边都可能导致卡滞 |
| 按钮轴向关系 | 外墙面到开关触点约 `2.6～3.4 mm` | 来自照片和壁厚推导；原按钮隐藏顶杆长度、静止余量和有效行程仍未实测 |
| 两个 HDMI | 原壳六边形孔 | 真实连接器鼻端轮廓未测量，自动覆盖检查刻意标为“未计算” |

这意味着当前订单必须标记为“fit-check prototype”。如果 `05/07` 太紧、接缝无法闭合或按钮卡滞，应回到参数源增加独立制造补偿；不要在切片器里全局放大，也不要把打磨后的尺寸误认为 CAD 正确。

## 6. FDM PETG 切片起始参数

以下是 `0.4 mm` 喷嘴、常见 PETG 的保守起点，不是对所有打印机通用的固定配方。喷嘴温度、热床温度、流量和最大速度应从所用耗材厂商配置开始。

| 参数 | 起始建议 |
| --- | --- |
| 层高 | `0.20 mm`；`1.2 mm` 板正好形成 6 层 |
| 线宽 | 约 `0.42～0.45 mm` |
| 墙线 | 4 道；启用 Arachne/薄壁处理，并在切片预览里确认 `1.8 mm` 侧墙没有缺线 |
| 顶/底实心层 | 至少 6 层，确保 `1.2 mm` 板完整实心 |
| 填充 | `25～35%` gyroid；薄板和侧壁主要由实心层/墙线决定，盲目 100% 填充不能解决翘曲 |
| 外墙速度 | 先用 `30～50 mm/s` 的保守范围，细节和桥接处进一步减速 |
| 附着 | 清洁平台，使用 `8～12 mm` brim 或四角 mouse ears；先不用 raft |
| 象脚补偿 | 从已标定的机器配置开始；不要为了某一个孔临时全局缩放模型 |
| 支撑 | 默认关闭；只在切片桥接预览显示接口上沿失败时局部绘制，阻止支撑进入螺钉孔和按钮孔 |

`0.8 mm` 高加强筋在 `0.20 mm` 层高下应形成 4 个完整层。切片预览必须确认每一条筋都连续、与基础板融合，没有被薄壁过滤器删除；若切片器丢失筋路，应先修正线宽/薄壁设置，不能通过整体缩放模型补救。

摆放方向：

- 上壳：外顶面贴平台，内腔朝上。
- 下壳：外底面贴平台，内腔朝上。
- 不要竖起来打印整壳，也不要把两个壳套在一起打印。

这样可让四根柱沿 Z 方向生长，并用最大平面稳定零件。代价是外顶/底面会保留平台纹理，接口孔上沿则需要检查桥接质量。开启切片预览后逐层检查：风扇圆孔、按钮圆孔、USB/HDMI/RJ45 上沿、`Ø2.5/3.4 mm` 孔和圆角接缝不能被错误封闭。

## 7. MJF/SLS 下单备注模板

可把下面文字随订单提交给工程师：

> 两个独立电子设备外壳试装件，单位 mm，不允许缩放或镜像。上壳、下壳各 1 件，材料拟用 MJF PA12S/PA12。关键结构：顶底连续基础板 1.2 mm，内侧加强筋宽 1.5 mm、高 0.8 mm（筋路处局部总厚 2.0 mm），侧壁 1.8 mm，上柱 Ø6.4/导孔 Ø2.5，下柱 Ø6.4/通孔 Ø3.4，按钮孔 Ø9.4。请重点审核大平板翘曲、筋路完整性、薄壁完整性、深孔清粉和孔径偏差；未经确认不要自动加厚、封孔或修改模型。首套不喷漆，所有孔和内腔需清粉。两个零件的预览外包络均应约为 106.6 × 109.5 × 26.8 mm；上壳/下壳体积应约为 24.13/23.02 cm³。

如果工程师认为 `1.2 mm` 平板不可稳定制造，要求对方给出工艺原因和建议最小值，再修改 CAD。不要允许平台只对局部“自动加厚”，否则仓库参数、STEP 和实物将失去对应关系。

## 8. 收货后的处理

1. 签收后先拍照检查裂纹、缺角、分层、翘曲和孔内残粉；工业平台有售后时限，应在平台规定时间内反馈。嘉立创当前须知要求签收后 3 日内反馈少件、变形或坏件。[嘉立创下单须知](https://www.jlc-3dp.cn/technicalColumnsDetails/40026.html)
2. 用卡尺记录两个零件的 X/Y 外尺寸、四孔中心关系、板面平面度和壳体总高。
3. 先用手清理粉末、拉丝和毛边。不要用电钻高速强行扩孔；需要修孔时用对应钻头或铰刀手动、低速并从非外观面进入。
4. `Ø3.4 mm` 下孔可清到螺钉自由通过；`Ø2.5 mm` 上导孔在紧固件方案确定前不要随意扩大。
5. `Ø9.4 mm` 按钮孔只去除毛边，先记录原始孔径，再判断是否需要极少量修整。
6. 清粉、清屑后再让主板接近壳体。尼龙粉末和塑料切屑不得留在 PCB、接口或风扇内。

## 9. 推荐的螺钉试装方案

当前 CAD 为：下壳 `Ø3.4 mm` 通孔，上壳 `Ø2.5 mm` 导孔，柱外径 `Ø6.4 mm`，底面没有螺钉头沉孔。

第一次可准备：

- `M3 × 18 mm` 盘头或圆头机螺钉 4 枚；
- M3 平垫圈 4 枚；
- M3 手用丝锥及手柄；
- 备选 `M3 × 20 mm`，只在确认不会顶到底/顶到顶板后使用。

从底板外表面到 PCB 顶面约 `13 mm`，`M3 × 18 mm` 理论上可在上柱获得约 `5 mm` 啮合；垫圈会略微减少啮合量。PA12 或 PETG 上柱可在确认孔位和壁厚后手工攻 M3 螺纹，再使用机螺钉低扭矩夹紧。不要用电动工具直接把普通机螺钉暴力拧入 `Ø2.5 mm` 导孔。

注意：

- 当前没有沉头结构，不能用沉头螺钉强行楔入；盘头/圆头会突出底面。
- 热熔螺母的外径、长度和安装余量尚未进入 CAD，不要直接把 M3 热熔螺母熔进当前 `Ø6.4 mm` 柱。
- 塑料专用 PT 自攻螺钉需要按具体牙型重新核对底孔，不能只凭“M3”三个字替代计算。
- 如果需要成品底面平放，下一版应增加螺钉头沉孔或脚垫，而不是在本版上强行沉头。

## 10. 正确的装配和验收顺序

### A. 无主板检查

1. 将上下壳空合，观察六段接缝是否能自然闭合。
2. 不使用螺钉，检查四柱能否同轴接近；不能靠扭壳对齐。
3. 将原按钮装入 `Ø9.4 mm` 孔，确认可自由滑动和回弹。
4. 用实际 USB、HDMI、网线、DC 和耳机插头逐孔插入，先确认壳体孔本身没有明显毛边阻挡。

### B. 主板无电试装

1. 断开所有电源、存储和外设，先把原按钮装入上壳。
2. 按项目装配逻辑，将主板先放入上壳；不得压风扇、鳍片或接口来迫使四孔就位。
3. 观察两个 06 USB 是否先到达墙面基准，确认板载开关触点没有进入墙体，也没有在静止状态被按钮持续压住。
4. 安装下壳，使四颗螺钉先都只啮合 1～2 圈；按对角顺序逐步、低扭矩收紧。
5. 如果任一角必须明显压弯 PCB 才能进孔，立即停止。螺钉用于夹紧，不用于把错误孔距拉到一起。
6. 逐一插入所有实际线缆，确认插头外壳、应力释放胶套和卡扣都有空间；不能只看金属接口鼻端能否穿孔。

### C. 按钮专项验收

1. 未通电时按压至少 25 次，感受每次是否有清晰触发和完整回弹。
2. 松手后板载开关必须完全释放；轻触外按钮侧面或晃动机壳不得自行触发。
3. 若装上侧壳后按钮持续顶住开关、无行程或孔内卡滞，停止使用并记录：按钮外露量、静止间隙、触发行程和回弹情况。
4. 当前照片推导的外墙面到开关触点为约 `2.6～3.4 mm`，不能替代对原按钮隐藏顶杆长度的实测。

### D. 通电验收

只有在无电检查全部通过后才通电：

1. 确认内部无尼龙粉、塑料丝、金属屑和遗落螺钉。
2. 确认风扇进气圆孔、04 鳍片排风通道和叶轮均无阻挡。
3. 首次开机保持外壳可随时断电，不要无人值守。
4. 先做 10～15 分钟空闲测试，再做 30～60 分钟逐步负载测试，记录环境温度、CPU/SSD 温度、风扇转速和壳体是否软化或翘曲。
5. 出现异味、按钮误触、风扇摩擦、接口断连、PCB 弯曲或局部异常升温时立即断电。
