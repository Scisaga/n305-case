# 照片到 CAD 的固定流程

更新日期：2026-08-20

本流程解决本项目此前反复出现的根本问题：把照片中的透视、局部像素比例或视觉间距误当作机械坐标，导致参考图看似合理但无法可靠生成 STL。

## 数据链

```text
用户实测 / 卡尺读数
          │
          ├── 决定标称毫米尺寸和 PCB 包络
          │
PCB 对齐标定 ── 决定统一 Y/Z 中心
          │
原壳照片 ────── 只决定接口顺序和特殊轮廓
          │
          ▼
带 PCB 边界的正投影审图 + 机器可读参数
          │
          ▼ 用户确认
参数化 CAD → STEP/STL → 几何验证
```

照片局部网格属于证据层，正投影参考属于机械层，两者不得合并为同一坐标系。

## 每次建模前的检查清单

1. 当前物体属于照片证据、面板孔、主板实体、避让体还是外壳实体？
2. 每个尺寸的来源是用户实测、标尺照片、PCB 对齐标定还是推断？
3. 是否已经明确 PCB 原点、轴方向、观察方向和镜像关系？
4. 审图是否使用单一毫米比例并显示 PCB 边界？
5. 非标准轮廓是否来自原壳，而不是套用接口标准外形？
6. CAD 是否直接读取参数文件，而不是读取 PNG 像素？
7. 接触件是否真的接触，组合件是否存在完整装配/承力路径？
8. 是否只生成了用户已经批准进入三维阶段的对象？
9. 是否把 PCB 总体外接矩形误当成局部真实边界？遇到缺口、台阶或接口间内缩时，必须从同一正投影照片建立局部轮廓层级。
10. 面板位置是否由该面的最外侧实体约束件决定？不得用更矮或更内缩的开关触点替代 USB/接口肩部作为墙面基准。
11. 总跨距与设计余量是否分开记录？原壳侧壁实测厚 `1.8 mm`、04–06 内跨距约 `103.0 mm`；原壳 05–07 约 `110.5 mm` 包含无需复制的额外留空，当前设计仍使用 05/07 各 `0.20 mm` 试装余量。

## 审图最低内容

正投影参考图必须同时包含：

- PCB 实际边界和厚度；
- 统一毫米比例或可验证的尺寸链；
- 观察方向及相邻的 04/05/06/07 面；
- 每个孔的中心 Y/Z；
- 宽、高、直径、圆角和附加 relief；
- 实测、标定和 provisional 状态；
- “未加入打印余量”或已加入何种加工余量的明确说明。

## 三维验证最低内容

- PCB X/Y/Z 包络与四个安装孔；
- 接口和开关是否位于正确边与正确中心；
- 裸组件最高、最低 Z 和总厚度；
- 风扇、冷板、托板、热桥、鳍片之间是否存在连续接触；
- 面板开孔与接口功能区域的覆盖检查；
- 物理实体与 clearance/keepout 是否分开；
- STEP/STL/JSON/PNG 清单是否与文档一致。

## 可复用提示词

下面的提示词用于继续本项目或处理新的表面；方括号内容按任务替换：

> 处理 `[对象/表面]` 时必须遵守仓库 `AGENTS.md`。先读取现有参数、照片索引和审阅记录，再输出一张“数据来源表”，逐项区分：用户实测、卡尺读数、PCB 对齐标定、照片轮廓证据、provisional 推断。使用唯一坐标系 `+X=06, -X=04, +Y=07, -Y=05, +Z=风扇面, PCB底面Z=0`。01/02 卡尺图只确认 PCB 的 `100.0 × 105.5 mm` 平面，不把总宽差值对称平分成接口突出量；接口突出必须逐面、逐件记录，04 鳍片与接口不得共用前沿。照片只取接口语义和特殊轮廓，不把透视斜度、照片间距、不同 Z 高度造成的视差或局部网格当作全局机械位置。先生成统一毫米比例、带 PCB 边界、观察方向、中心 Y/Z、尺寸和来源的正投影审图；PNG 仅供审核，机器参数必须单独保存。外壳 04/06 应是各自完整、带贯通开孔的连续平面侧壁，不承担 PCB 贴边定位；面板位置应由最外侧真实接口而非内缩开关决定。原壳 `1.8 mm` 侧壁和约 `103.0 mm` 的 04–06 内跨距作为实测约束；原壳 05–07 的 `110.5 mm` 额外留空不进入当前紧凑设计。PCB 主要由原四孔和螺柱定位。只有我明确确认的对象才能进入 STEP/STL。三维 CAD 直接读取毫米参数，物理实体、面板孔、插头通道和 keepout 分开。组合件必须有真实接触/装配路径。导出后检查 PCB 包络、四孔、Z 包络、逐件接口突出、鳍片齐边、接口顺序和方向、孔对接口覆盖、连续墙体、接触链、输出文件清单，并明确列出仍属 provisional 的尺寸。未经批准不要生成外壳，也不要复用已撤销的旧 STL/STEP。

执行时必须给出以下四项，而不是只给一张看起来合理的图：

1. 采用的数据与来源；
2. 可审阅正投影或三维预览；
3. 参数源、生成命令和输出路径；
4. 自动校验结果与待实物确认项。
