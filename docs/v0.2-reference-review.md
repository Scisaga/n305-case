# V0.2 当前审阅基准

更新日期：2026-08-20

状态：**已恢复 PCB 边界的 04/06 正投影开孔审阅基准，并重建主板三维参考；外壳尚未生成。**

## 1. 仍然有效的用户约束

- 正对风扇面时：鳍片在下，左边 07，上方 06，右边 05，下方 04。
- 顶板、底板精确为 1 mm，不额外增加风扇避让高度。
- 外壳最终为上壳、下壳两件，原机按钮复用；不增加独立外壳螺丝位。
- 主板先放入上壳，再安装下壳；最终利用主板原有四孔建立夹紧链。
- 旧连续卡槽、绕壳舌槽和额外四个壳体螺丝位不采用。

这些是功能/装配约束，不等于已经建立了可生成的三维几何。

当前面板坐标统一为：PCB 04/06 边长 `105.5 mm`，PCB 厚 `1.5 mm`；`Y=0` 位于边中心，`+Y` 指向 07，`-Y` 指向 05；`Z=0` 是 PCB 底面，`+Z` 指向风扇面。
机器可读的当前数据为 [panel-apertures.json](./panel-apertures.json)，源定义为 [n305_panel_reference.py](../src/n305_panel_reference.py)。

## 5. 当前主板三维参考

当前主板模型从 [n305_mainboard_reference.py](../src/n305_mainboard_reference.py) 重新生成，说明见 [motherboard-reference.md](./motherboard-reference.md)。它包含 PCB、逐孔安装孔、接口实体、板载开关、连续连接的散热组件以及独立避让体；构建验证明确记录 `enclosure_geometry_generated=false`。

接口实体的中心使用本页已审阅坐标。未实测的连接器隐藏壳体和散热局部细节均按照片近似或保守包络处理，不覆盖本页的面板开孔尺寸。

## 6. 进入外壳三维前必须完成

1. 审阅当前主板三维参考的四孔、接口实体、散热布局和避让体。
2. 对每个接口执行“接口实体/插头通道 vs 面板开孔”的覆盖检查。
3. 明确每个面/边的装配结合方式和主板四孔夹紧链。
4. 上述结果通过审核后，才生成外壳 STEP/STL。
